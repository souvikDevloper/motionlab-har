# MotionLab

Smartphone activity recognition with real trained models, browser inference, recorded sensor replay, CSV prediction and measured robustness experiments.

This repository contains the standalone hosted application and its assets. All prediction computation runs in the browser. The Python research implementation is available from the application downloads.

Dataset: Reyes-Ortiz et al. (2013), UCI Human Activity Recognition Using Smartphones. DOI 10.24432/C54S4K. CC BY 4.0. See downloads/DATA_ATTRIBUTION.txt.
